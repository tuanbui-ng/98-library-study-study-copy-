# The 98% Library: study copy

This is the study copy of the 98% Library, a collection of graded readers written to Paul Nation's BNC/COCA word family lists by [Dr Tuan Bui](https://scholar.google.com/citations?user=PBwEZ7kAAAAJ&hl=vi). Students sign in with a participant code. The site records reading times, glossary look-ups, comprehension answers, ratings and timed reading tests for research.

For permission to use the readers, or for any enquiries, please contact tuanbn@hanu.edu.vn.
